# Rewrite Rules

Use this after publication or before refreshing old drafts.

## Timing

- Day 0: check title, formatting, disclosure, and obvious mistakes.
- Day 3: review early exposure and title clarity.
- Day 7: review views, inflow keywords, comments, and clicks.
- Day 14 to 30: decide whether to update, consolidate, or leave the post alone.

## Rewrite Decisions

If views are low and exposure is weak:

- Improve title accuracy and specificity.
- Add source freshness and better opening.
- Check duplicate intent.

If views are okay but reading/click signals are weak:

- Improve first screen.
- Add comparison table.
- Add FAQ.
- Add clearer buyer criteria.

If affiliate clicks are high but conversion is weak:

- Recheck product fit.
- Add price bands and watch-outs.
- Replace broad recommendation with reader-type recommendation.

If an event expired:

- Update with new dates if available.
- Add "ended" note if useful.
- Avoid publishing a near-duplicate unless conditions changed meaningfully.

## Do Not

- Make repeated tiny edits without a clear hypothesis.
- Change titles into clickbait.
- Delete many posts at once without evidence.
- Rewrite another creator's current article.
