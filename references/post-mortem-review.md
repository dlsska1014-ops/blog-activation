# Post-Mortem Review

Use this when a post performs unusually well or poorly.

## Review Questions

1. Was the topic timely?
2. Was the reader intent clear?
3. Did the first screen make the value obvious?
4. Was the title accurate and distinct?
5. Did the layout help scanning?
6. Were images useful or decorative?
7. Was the affiliate ratio appropriate?
8. Were facts current and sourced?
9. Did the post overlap recent content?
10. What should be repeated, changed, or stopped?

## Good Performance

If a post performs well:

- Add the pattern to `style-memory.md` only if reusable.
- Add a cluster follow-up if reader intent supports it.
- Consider a related FAQ or comparison post.
- Do not duplicate the post with minor keyword changes.

## Weak Performance

If a post performs poorly:

- Check exposure with `search-exposure-check.md`.
- Check duplicate risk.
- Review title and first-screen clarity.
- Add comparison, FAQ, or source freshness if thin.
- Avoid panic edits.
