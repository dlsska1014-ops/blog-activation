# Keyword Clusters

Use this file to build topical authority without publishing duplicate posts. A cluster is a group of posts that serve different reader intents around one topic.

## Cluster Roles

- Pillar post: broad guide that explains the topic and links to supporting drafts.
- Event/update post: time-sensitive facts, dates, conditions, and changes.
- Buying guide: selection criteria, budget scenarios, comparison table.
- Mistake/FAQ post: common confusion, exclusions, edge cases.
- Affiliate post: product recommendations only when buyer intent is clear.

## Rules

- Do not publish multiple posts with the same reader intent.
- Make every support post answer a distinct question.
- Link or reference older related posts when appropriate.
- Update an existing post when only dates or small conditions changed.
- Build clusters around durable topics: seasonal goods, benefit events, public support, electronics buying, household problem solving.

## Example Cluster

Topic: electronics payback event

- Pillar: "event conditions and who should check it"
- Support: "budget-based purchase scenarios"
- Support: "common exclusions and mistakes"
- Affiliate: "accessories or related products only if useful and disclosed"

## Reject A New Post If

- It only changes the title from a recent post.
- It targets the same reader question as yesterday's post.
- It exists only to add another affiliate link.
- It cannot add a table, checklist, calculation, or new source update.
