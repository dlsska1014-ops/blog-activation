# Emoji And Emoticon Guide

Use emoji and emoticons lightly. The goal is a natural blog tone, not decoration.

## Default Usage

- Use 0 to 3 emoji or emoticons per post unless the user asks for a brighter tone.
- Use them mostly in intros, checklist headers, or light transitions.
- Avoid putting emoji in every heading.
- Avoid using emoji to replace clear structure.

## Safe Markers

Use these when they improve scanning:

- `✔` for check points.
- `※` for cautions.
- `Q.` and `A.` for FAQ.
- `:)`, `ㅎㅎ`, or `!` only when the tone truly fits.

## Good Uses

- "구매 전에 이 부분은 꼭 확인해보세요 ✔"
- "※ 행사 조건은 결제 직전 한 번 더 확인하는 게 안전합니다."
- "Q. 온라인 구매도 혜택이 되나요?"

## Avoid

- Too many hearts, fire icons, sirens, or exaggerated symbols.
- Emoji-heavy titles for information posts.
- Emoticons in serious public benefit, finance, safety, or policy posts.
- Forced cuteness when the topic needs trust.

## Tone Selection

- Event/benefit post: calm, practical, 0 to 2 markers.
- Shopping guide: friendly, 1 to 3 markers.
- Affiliate TOP 5: practical, markers only for comparison.
- Public benefit/news: minimal markers.
