# Style Memory

Update this file only with durable patterns learned from recent high-performing Naver Blog and Tistory posts. Do not store copied text from other creators.

## Current Baseline

- Prioritize Naver Blog readability: short paragraphs, visible breathing room, and clear image placement.
- Begin with a reader problem, not a generic topic introduction.
- Use tables for price, benefit, eligibility, product comparison, and TOP 5 summaries.
- Keep the tone warm, practical, and specific.
- Use light emoticons or emoji only when they match the post mood.

### 2026-06-27 Visual And Editorial Correction

- Topic area: long practical explainers and event-condition posts.
- Observed title pattern: a concrete failure condition and a bounded checklist create a clearer promise than a broad "complete guide" title.
- Opening pattern: answer the failure situation first, then state what was checked and where the decision changes.
- Layout pattern: alternate short verdicts, concrete scenarios, evidence, and cautions instead of giving every section the same rhythm.
- Image/table pattern: deterministic cards are useful for one comparison or checklist, but a full set of similar cards feels templated. Start with a believable scene, include evidence or an explanatory visual, and limit text cards to two.
- Reusable lesson: influencer-like trust comes from specific observation, useful visual proof, honest limits, and captions. It does not require fake first-person experience or decorative excitement.
