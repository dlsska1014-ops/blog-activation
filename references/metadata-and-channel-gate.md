# Metadata And Channel Gate

Use this immediately before every Naver or Tistory draft-save or publish action.

## Public Copy Boundary

- Classify the article as `information`, `seasonal`, `affiliate`, or `sponsored` before writing.
- In `information` and `seasonal` public copy, do not mention affiliate links, partnership, sponsorship, monetization, commissions, or the absence of those items.
- Keep operational notes such as "no verified affiliate link" in the private run log only.
- In `affiliate` or `sponsored` copy, include only the disclosure required for that article. Do not add internal workflow commentary.

## Tag Gate

- Prepare focused tags before opening the editor.
- Require at least three relevant tags in the final editor state. Prefer five to ten for Naver and four to eight for Tistory when each tag has clear search intent.
- Mix one primary topic tag, two to four supporting intent tags, and useful seasonal or audience tags.
- Reject duplicate, irrelevant, excessively broad, or sentence-like tags.
- Recount visible tags after opening the final menu. A tag file on disk is not proof that tags reached the editor.
- For Tistory, verify the visible tag input is active before typing. If preview or another footer control opens, close it and retry from the visible tag field.

## Naver Topic Gate

- Open the final save/publish menu and inspect the visible topic choices.
- Choose the closest topic based on the article's dominant reader intent, not merely one keyword.
- Use a practical living topic for household how-to content, a travel/leisure topic for camping or outings, and a shopping/product topic for actual product comparisons when those choices are visible.
- Never invent a topic label or leave the topic unset. Record the exact visible selected label in editor verification.

## Tistory Category Gate

- Select the closest existing blog category before the final action.
- Do not create a new category during an unattended run unless the user explicitly approved category management.
- Adapt title, H2/H3 structure, meta description, image alt text, and tags rather than pasting the Naver body unchanged.
- Record the exact visible category and final tag count in editor verification.

## Stop Conditions

Stop before the final action when any of these is true:

- a non-affiliate public body exposes monetization or affiliate workflow language,
- fewer than three tags are visible,
- tag entry opened preview or another panel and the final tag count was not reverified,
- the Naver topic or Tistory category is unset,
- the selected classification conflicts with the article's main reader intent,
- required affiliate or sponsored disclosure is missing.
