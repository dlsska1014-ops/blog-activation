# Experiment Log

Use this to turn blog performance into deliberate experiments.

## Experiment Types

- Title pattern.
- First-screen opening.
- Layout pattern.
- Thumbnail type.
- Affiliate link placement.
- Product category.
- Keyword cluster.
- FAQ depth.

## Experiment Template

### YYYY-MM-DD - Experiment Name

- Hypothesis:
- Posts affected:
- Change made:

- Result:
- Decision:

## Decision Rules

- Repeat if the signal improves across at least 2 to 3 comparable posts.
- Keep testing if results are mixed but no trust risk appears.
- Stop if the change lowers trust, increases duplicate risk, or makes writing feel forced.
- Do not change several variables at once unless necessary.

## Useful Metrics

- Views.
- Search inflow keywords.
- Exact title exposure.
- Affiliate clicks.
- Comments/questions.
- Saves or likes if available.
- Conversion if available.

## Examples

Title experiment:

- Hypothesis: mistake-prevention titles get better search clicks for event posts.
- Change: use "놓치기 쉬운 조건" title pattern.
- Metric: views and search inflow after 7 days.

Layout experiment:

- Hypothesis: summary table in the first third improves reading and affiliate clicks.
- Change: move comparison table above product list.
- Metric: clicks and comments after 7 days.
