# Platform Guidelines

## Naver Blog First

Prepare Naver Blog drafts with:

- 1 to 3 title options under natural Korean search phrasing.
- Short paragraphs, often 1 to 3 lines.
- Generous spacing between thought blocks.
- Image placement notes every 2 to 4 sections when useful.
- Clear section dividers, but avoid making the article look like a report.
- Tags at the end.

Suggested Naver layout:

1. Hook opening.
2. Quick summary.
3. Main explanation with subheadings.
4. Table or comparison block if readers need to choose.
5. FAQ.
6. Final recommendation or next step.
7. Tags.

## Tistory Second

Adapt Naver drafts for Tistory with:

- More explicit H2/H3 headings.
- A short meta description.
- A tighter table of contents when the post is long.
- Source notes and checked dates.
- More evergreen phrasing when possible.
- Descriptive image alt text, a category, and mobile-safe tables.
- A canonical or duplication plan when substantially similar content also appears on Naver.

## Draft-Save Rule

Default to preparing draft content only. Publish only when the latest explicit instruction enables it for the current batch.

If browser automation is used, follow `live-publish-runbook.md` and the platform runbook. Do not repeatedly reconfirm an already approved batch, but verify every final result.
