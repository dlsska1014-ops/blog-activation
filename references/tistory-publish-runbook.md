# Tistory Publish Runbook

Use this after the Naver version is complete. Treat Tistory as the active secondary channel unless the user explicitly excludes it for the current run.

## Adaptation Gate

Do not paste the Naver body unchanged. Prepare a Tistory version with:

- One SEO title and a short meta description.
- Real H2/H3 structure instead of decorative plain-text headings.
- A compact table of contents only when the article is long enough to benefit.
- Source names and checked dates for time-sensitive facts.
- Descriptive image alt text.
- A category and focused tags.
- A canonical or duplication plan when substantially similar content is published on both platforms.

Keep the facts and recommendation basis consistent across platforms. Change structure and phrasing for the platform, not the factual meaning.

## Editor Procedure

1. Read `tistory-editor-safety.md` and verify the visible Tistory blog.
2. Use one editor tab in basic mode. During the first three verified Tistory runs, transfer one draft only.
3. Confirm that no recovery prompt, mode-switch dialog, stale autosave, or second editor tab is present.
4. Insert the adapted title, description, and complete body once before adding images.
5. Select a category and add at least three focused tags.
6. Upload one prepared image at a time through a verified attachment flow and confirm its exact body anchor before continuing.
7. Add concise alt text and source captions. Never paste bulk body text while an image or caption is selected.
8. Verify image count, unique image fingerprints, zero orphan figures, image order, caption length, non-duplicated body beginning and ending, category, tags, and zero active uploads.
9. Save or publish according to the current run mode.
10. Verify the draft-count change or public URL, then record a separate Tistory receipt.

## Stop Conditions

- The target blog or category is uncertain.
- The editor cannot confirm image completion.
- The Naver body was copied without Tistory adaptation.
- A table or image visibly overflows mobile width.
- The final URL or draft state cannot be verified.
- Fewer than three tags are visible or the category is unset.
- HTML or Markdown mode was opened during an unattended run.
- More than one Tistory editor tab is open.
- Body text appears inside an image caption or alt-text field.
- The body was replaced or bulk text was inserted after the first image upload.
- Images are grouped at an unintended bookmark instead of their section anchors.
- Any image fingerprint repeats, the editor contains more figures than expected, an empty figure remains, or a body block repeats.
- The browser disconnects, a mode-switch confirmation appears, or an unsaved recovery state is uncertain.

Do not let a Tistory failure trigger a duplicate Naver post. Report the two platform results independently.
