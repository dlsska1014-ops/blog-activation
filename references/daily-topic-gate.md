# Daily Topic Gate

Use this before drafting the three daily posts. The goal is to prevent weak, repetitive, or affiliate-first topics from entering the workflow.

## Three Questions

Answer these for every topic candidate:

1. Why does this post need to exist today?
2. What specific reader question does it answer?
3. What original value will it add beyond a summary or product list?

Reject the topic if any answer is vague.

## Required Value Type

Each selected topic must include at least one:

- Current verified fact.
- Comparison table.
- Budget scenario.
- Mistake-prevention section.
- Eligibility or condition checklist.
- Reader-type recommendation.
- FAQ based on likely confusion.

## Daily Mix Check

Before drafting three posts:

- At least one post must be non-affiliate and information-first.
- No two posts should target the same reader intent.
- The Coupang Partners post must have clear buyer intent.
- At least one post should strengthen a keyword cluster.
- No post should exist only because a keyword looks popular.
